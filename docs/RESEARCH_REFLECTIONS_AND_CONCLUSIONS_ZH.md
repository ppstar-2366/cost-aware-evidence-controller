# 实验感悟、研究结论与未来工作

本文档不是新的实验结果，而是基于现有正式数据形成的研究层面反思。它适合用于论文的“结果讨论”“总结与展望”、个人工作总结以及答辩陈述。

## 1. 这项研究真正说明了什么

本项目最重要的发现并不是某一种方法取得了最高的单项分数，而是科学论文问答中的证据选择存在清晰的质量—成本矛盾。

固定 BM25 top-k 的行为非常直观：随着 k 增大，系统更容易覆盖金证据，但需要交给后续模型阅读的文本也快速增长。BM25 top-20 的 Evidence Recall 达到 0.9519，但平均估算 token 为 4,144；top-5 只需要 1,156 token，但 Recall 降至 0.5646。由此可以看到，“多取证据”能够提高覆盖，却不是没有代价的解决方案。

ControllerV3 的意义在于提供了一个可解释的中间选择：它不是为每个问题机械地使用同一个 k，而是从 top-3 出发，根据数据、结果、方法、定义或图示问题采取不同扩展动作。最终平均 Recall 为 0.7063、Hit Rate 为 0.8675、估算 token 为 1,640，质量和成本都位于 BM25 top-5 与 top-10 之间。

因此，本研究更适合被概括为：

> 设计并验证了一种面向科学问答的轻量证据预算控制机制，使证据选择过程能够根据问题类型动态调整，并对每项质量收益及其阅读成本进行量化。

## 2. 实验中得到的核心认识

### 2.1 最大召回不等于最佳系统

如果只看 Evidence Recall，BM25 top-20 明显最好；但实际系统还要考虑模型上下文长度、推理资源和噪声证据。研究价值不应只建立在“是否找到更多证据”，还应包括“为了增加这些证据付出了多少上下文成本”。

这也是为什么论文应同时报告：

- Evidence Recall；
- Question Hit Rate；
- Average Best Overlap；
- Avg. Estimated Tokens；
- Recall per 1k Tokens。

任何单一指标都会丢失一部分信息。

### 2.2 单位成本指标也不能单独决定优劣

BM25 top-1 的 Recall per 1k Tokens 最高，但它只命中 34.44% 的有金证据问题。低预算方法很容易获得较高的“平均效率比”，却不一定达到可接受的绝对质量。

这说明成本感知研究应讨论可接受的质量约束。例如实际部署者可能先要求 Hit Rate 不低于某个阈值，再在满足要求的方法中选择成本更低者，而不是无条件选择 Recall/1k 最大的方法。

### 2.3 章节信息有作用，但不是免费收益

完整 ControllerV3 相比无章节扩展版本：

- Recall 提高 3.04 个百分点；
- Hit Rate 提高 3.31 个百分点；
- Average Best Overlap 提高 2.38 个百分点；
- 平均增加 0.45 个证据单元；
- 平均增加约 97 个估算 token。

因此章节扩展确实带来额外覆盖，但 Recall/1k 从 0.4380 略降至 0.4307。这不是消融失败，而是典型的“用额外预算换覆盖质量”。论文如果把这一点讲清楚，反而比只报告正向指标更有研究深度。

### 2.4 生成模型看到的内容与检索输出不一定相同

检索文件保存完整 retrieved units，而生成 prompt 对证据部分设置了 6000 字符上限。最终 BM25 top-10 与 top-20 的 156 对 prompt 全部相同；ControllerV3 与 top-10 也有 134 对相同。

这一现象说明端到端系统中至少存在三个不同预算：

1. 检索器选择了多少证据；
2. prompt builder 实际放入多少证据；
3. 模型 tokenizer 实际处理多少 token。

如果只记录第一个预算，就可能错误解释下游结果。这个审计发现是论文中很有价值的方法学反思。

### 2.5 temperature=0 不等于逐字符完全确定

BM25 top-10 与 top-20 的 prompt 完全相同，模型、temperature 和 seed 也相同，但仍有 9 对生成答案文本不同。说明跨时段、断点恢复的本地 Ollama 推理没有实现严格的 byte-level determinism。

因此不能把 top-10 与 top-20 约 0.005 的 F1 差异解释成检索方法影响。更稳妥的做法是把生成实验定位为下游可用性验证，并在未来工作中加入重复推理、输出方差或确定性配置检查。

### 2.6 可恢复性本身也是实验质量的一部分

在低配置机器上运行 624 次本地生成，锁屏、休眠、关机或请求超时是现实问题。使用逐行追加 JSONL、成功键检测和分方法续跑，使最终实验能够跨多次会话完成。

对于真实研究工程，能够恢复、核验和追踪的实验流程往往比一次性运行成功更重要。最终新增的审计 JSON 和 SHA-256 清单，使论文表格能够回溯到逐问题原始记录，而不是只剩一张无法验证的汇总表。

## 3. 原始设想与最终证据之间的关系

### 得到支持的设想

- 大 k 提高证据覆盖，同时显著增加证据成本；
- 问题感知控制器可以形成不同于固定 top-k 的动态预算；
- section-aware expansion 能改善数据和定义类问题所需证据的整体覆盖；
- 较低成本的 ControllerV3 证据可以支持本地小模型取得与固定 top-k 相近的下游 F1/EM；
- 动作记录与错误分类可以帮助解释控制器为什么成功或失败。

### 只得到部分支持的设想

- ControllerV3 没有在答案 F1 上超过所有基线，结果只能说明“接近”而不是“更优”；
- ControllerV3 的 Recall per 1k Tokens 不是最高，因此其优势不是单一效率比，而是中等预算下的综合平衡；
- 下游生成受统一字符上限影响，不能完全反映原始检索证据量差异。

### 当前不能证明的内容

- 方法在 QASPER 全量、其他数据集或其他领域上的泛化能力；
- 相对 dense retriever、reranker 或学习型控制器的优势；
- 任意两种答案 F1 差异具有统计显著性；
- 方法在真实在线系统中具有更低延迟或更低货币成本；
- ControllerV3 达到当前最先进水平。

## 4. 研究贡献的推荐表述

可以将贡献总结为四点：

1. **结构化证据流水线**：把科学论文的摘要、正文、表格和图片 caption 统一转换为可检索单元，并保留 section 与来源元数据。
2. **可解释动态控制器**：提出从小预算开始、根据问题类型执行扩展和停止动作的 ControllerV3，每个被选择单元都能追踪到具体动作。
3. **质量—成本联合评估**：除证据召回和问题命中外，同时统计证据词数、估算 token 和单位成本召回，并通过章节扩展消融分析额外质量与成本。
4. **低资源端到端验证**：在本地 Qwen2.5-3B 上完成 624 次回答生成，并审计 prompt 截断、断点续跑与输出非完全确定性。

这四点的价值在于完整性、透明性和可复现性，而不是依赖大规模计算资源获得绝对最高分。

## 5. 可用于论文“实验结论”的段落

以下内容可以结合学校格式改写：

> 实验结果表明，固定增加 BM25 检索数量可以持续提升证据覆盖，但同时带来显著的上下文成本。BM25 top-20 在验证子集上取得 0.9519 的 Evidence Recall，但平均需要约 4,144 个估算 token；BM25 top-5 的成本仅为 1,156 token，但 Recall 降至 0.5646。所提出的 ControllerV3 取得 0.7063 的 Recall 和 0.8675 的 Question Hit Rate，平均成本为 1,640 token，在 top-5 与 top-10 之间形成了可解释的质量—成本折中点。

> 消融实验进一步显示，章节感知扩展使 Evidence Recall 和 Question Hit Rate 分别提高 3.04 和 3.31 个百分点，同时平均增加约 97 个估算 token。这说明论文结构信息有助于定位定义和数据相关证据，但其收益伴随额外阅读成本。

> 在本地 Qwen2.5-3B 下游生成实验中，ControllerV3 的 Answer F1 为 0.2577、Exact Match 为 0.1218，与 BM25 top-5、top-10 和 top-20 的整体结果接近。由于生成 prompt 采用统一的 6000 字符证据上限，不同检索方法在多个问题上形成相同模型输入，因此该结果主要证明 ControllerV3 证据在固定上下文预算下具有可用性，而不能解释为其答案质量显著优于固定 top-k。

## 6. 可用于论文“总结与展望”的完整草稿

> 本研究围绕科学论文问答中的证据质量与阅读成本问题，构建了从论文结构化处理、证据检索、动态控制、质量—成本评估到本地答案生成的完整实验流程。针对固定 top-k 难以根据问题需求调整上下文预算的问题，本文设计了轻量、规则化的 ControllerV3。该方法首先读取少量高排名证据，再根据问题是否涉及结果、数据、方法、定义或图示采取相应扩展动作，并保留每项动作的新增证据和停止原因。

> 在 QASPER validation 前 50 篇论文的 156 个问题上，实验验证了固定 top-k 的覆盖收益与成本增长趋势。ControllerV3 的证据召回和阅读成本均位于 BM25 top-5 与 top-10 之间；去除章节感知扩展后，召回率和问题命中率均有所下降，说明章节结构对科学论文证据定位具有实际作用。进一步使用本地 Qwen2.5-3B 完成 624 次回答生成，结果显示 ControllerV3 在较低检索成本下可以维持与固定 top-k 相近的下游回答表现。

> 本研究仍存在若干局限。首先，控制器规则的设计和最终评估使用了同一 validation 子集，结果可能受到人工调优影响；其次，词法 overlap 和词数换算 token 均属于代理指标；再次，6000 字符提示词上限压缩了不同检索方法的下游输入差异；最后，当前实验未加入 dense retriever、统计显著性检验或人工忠实性评价。未来可以在独立 held-out 子集上冻结并验证控制器，引入语义检索与轻量 reranking，学习问题条件下的动态预算策略，并把 prompt 构建纳入统一成本控制，以获得更严格的端到端质量—成本分析。

## 7. 可用于中文摘要的结果句

> 实验在 QASPER 验证子集的 50 篇论文和 156 个问题上进行。结果显示，所提出的 ControllerV3 在平均约 1,640 个估算证据 token 下取得 0.7063 的证据召回率和 0.8675 的问题命中率，质量与成本均位于 BM25 top-5 和 top-10 之间。章节感知扩展相对消融版本使证据召回率提高 3.04 个百分点、问题命中率提高 3.31 个百分点。本地 Qwen2.5-3B 的下游生成结果表明，ControllerV3 的回答 F1/EM 与固定 top-k 基线总体接近。

摘要里不建议放入 prompt 相同性等复杂局限，可在实验讨论和有效性威胁中详细说明。

## 8. 可用于英文摘要的结果信息模板

下面是信息模板，正式英文论文应再统一术语和语言风格：

> Experiments were conducted on 156 questions from 50 papers in the QASPER validation split. ControllerV3 achieved an evidence recall of 0.7063 and a question hit rate of 0.8675 with an average estimated evidence cost of 1,640 tokens, positioning it between the BM25 top-5 and top-10 baselines in both retrieval quality and cost. Section-aware expansion improved evidence recall and question hit rate by 3.04 and 3.31 percentage points, respectively, over the corresponding ablation. Downstream generation with a local Qwen2.5-3B model showed that ControllerV3 maintained answer F1 and exact-match performance comparable to fixed top-k retrieval under a bounded prompt budget.

不要在英文摘要中使用 `significantly improved`，因为尚未做显著性检验。

## 9. 未来工作优先级

如果论文提交前还有实验时间，建议优先级如下：

### 优先级 1：独立 held-out 验证

冻结 ControllerV3 所有规则，在未参与错误分析的新论文子集上重新运行。这是当前最能增强论文可信度的补充。

### 优先级 2：把 prompt 构建纳入控制策略

当前检索成本和模型实际输入之间存在字符截断。未来可让控制器直接在 tokenizer token 预算内选择单元，并记录真正进入 prompt 的 unit ID。

### 优先级 3：置信区间与重复生成

对检索指标做按问题 bootstrap；对本地生成做多次重复，报告均值、方差和输出一致率，避免把小差异过度解释。

### 优先级 4：增加语义基线

加入轻量 sentence embedding retriever、hybrid BM25+dense 或 cross-encoder reranker，检验控制器在更强候选排序上的作用。

### 优先级 5：人工错误评估

从不同错误类别中抽样，由人工标注回答正确性、证据忠实性和证据充分性。这可以弥补 F1/EM 对语义等价答案不敏感的问题。

## 10. 高质量论文最重要的写作原则

- 重点强调问题定义、方法逻辑、质量—成本分析和可解释性；
- 所有结论都和具体指标、分母及数据文件对应；
- 主动披露 prompt 上限、validation 调优和计时不可比问题；
- 不把局限写成失败，而是说明当前结论的适用边界；
- 用消融和错误案例体现研究分析深度；
- 不用“高分”替代研究贡献，准确、可验证的论证本身更有说服力。

## 11. 个人实验感悟参考

如果学校要求项目总结或个人体会，可以结合自己的实际经历改写：

> 本项目使我认识到，一个完整的科研系统不仅包括提出方法和获得结果，还包括数据版本管理、实验参数记录、中断恢复、结果审计和对异常现象的解释。最初我更关注证据召回是否提高，但随着实验推进，我发现成本、上下文截断和生成器行为会共同影响端到端结果。特别是 top-10 与 top-20 prompt 完全相同这一现象说明，如果只观察最终分数而不检查中间数据，很容易得到错误结论。通过重新组织代码、保留逐问题输出并建立审计文件，我对可复现研究和严谨结果分析有了更具体的理解。
